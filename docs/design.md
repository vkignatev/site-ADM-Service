# АДМ-СЕРВИС — согласованные решения

Одностраничный сайт по структуре страницы DELTA, в тёмном графитовом оформлении. Цвет знака АДМ — насыщенный бордовый #A52336, подпись светлая. Геометрия исходного знака сохранена.

Лозунги: «Тушим риски. Строим доверие.» и «Когда каждая деталь работает на Вашу безопасность».

Новосибирск и область. Телефон +7 982 412 11 59. Цены индивидуальные. Остальные неподтверждённые контакты не добавляются.

Услуги: Готовим к проверкам МЧС России под ключ; Аудит в области пожарной безопасности; Пожарная сигнализация; Оповещение и эвакуация; Пожаротушение. Сохранён сервис существующих систем. Мониторинга, противодымной защиты и огнезащиты в каталоге нет. Предоставленный документ о лицензии не редактируется.

Один администратор: статистика, заявки, SMTP, тестовое письмо, доступ. Заявки сначала сохраняются, затем отправляются. Неотправленные обращения остаются в панели.

Размещение: виртуальный хостинг Webnames, PHP 8.1+ и MySQL; рабочая папка сайта public, приватные app/storage за её пределами. SQLite используется только для локальных проверок.
