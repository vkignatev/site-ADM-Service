# Панель управления

Палитра: graphite #1D1F22, slate #292C30, deep #181A1D, wine #A12739, pearl #F1F0EE, silver #B5B9C1. Логотип отдельно: насыщенно-бордовый #A52336. Типографика: Segoe UI для данных и форм, Bahnschrift для заголовков.

На широком экране — постоянная боковая навигация и рабочая область. На телефоне — верхняя компактная навигация и одна колонка. В таблице заявок допустима прокрутка внутри контейнера, а не всей страницы.

```
Логотип | Обзор сайта                         Период
Обзор   | Посетители / Просмотры / Заявки / Письма
Заявки  | Динамика посещений
Почта   | Источники / Устройства
Доступ  | Пояснение методов подсчёта
```

Обзор содержит только реальные данные выбранной установки. При отсутствии данных показываются нулевые счётчики и пустое состояние, демонстрационные значения не подставляются. В локальной конфигурации панель помечена «Локальный просмотр».

Заявки и почта — самостоятельные разделы. Карточка заявки показывает контакт, услугу, текст, статус доставки, число попыток и статус обработки. Запись сохраняется прежде SMTP-операции. В форме почты пустой пароль означает «не менять»; сохранённое значение никогда не показывается.

Тёмная панель следует существующему сайту, но использует более компактную типографику и контролируемые контрасты для чтения данных. Цифры и график не используются как декоративные обещания.
